# Изменения

## 1.5.1 — 2026-11-11

- **Самолечение при сбое проверки VPN.** Если после применения конфига проверка «трафик
  идёт через VPN» не прошла, панель больше не откатывает конфиг сразу: она проверяет
  каждый сервер по отдельности (`xkeen-happ-ctl probe-servers` — поднимает временный
  Xray с socks-входом на каждый outbound), пишет в журнал, какие именно серверы не
  пропускают трафик, и исключает только их, пересобирая конфиг без мёртвых. Если
  выбранный сервер был недоступен — переключается на первый живой. Полный откат на
  прежний рабочий конфиг остаётся только для случая, когда не работает ни один сервер.
- Так же проверяются Hysteria2 и другие UDP/QUIC-серверы.
- `state.json` получает поле `dead_servers` (теги исключённых серверов), в Telegram
  уходит предупреждение со списком недоступных серверов.



## 1.5.0 — 2026-11-11

- **Hysteria2: полноценная поддержка.** Парсер теперь учитывает `obfs=salamander` +
  `obfs-password` и кладёт их в `streamSettings.finalmask.udp` (без этого Xray-клиент не
  проходит рукопожатие с сервером, где включена обфускация); добавлены
  `hysteriaSettings.udpIdleTimeout` (60 с по умолчанию), запасной `auth` из параметра
  ссылки и ALPN `h3` по умолчанию. Актуально для подписок 3x-ui/Happ-формата.
- **Hysteria2 не участвует в TCP-пинге** (`xkeen-sub ping`): это UDP/QUIC-протокол, TCP-коннект
  к её порту недостоверен — такие серверы помечаются `alive: true`, `ping_ms: null` (в панели
  «—»), доступность видна по реальному трафику Xray/балансировщика.
- `xkeen-happ-doctor`: TCP-проверка серверов применяется только к TCP-протоколам, Hysteria2
  выводится отдельной строкой (UDP/QUIC).
- Shadowsocks-2022 в мультиюзерном формате SIP022 (`ss://method:serverPSK:userPSK@...`)
  покрыт тестами.
- Автотесты парсера: 48 проверок (было 33) — добавлены hy2+obfs, alpn по умолчанию,
  отсутствие `finalmask` без obfs, SS-2022.



## 1.4.3 — 2026-11-10

- вкладка «Устройства»: список больше не может «упасть» из-за формы ответа RCI — конфиг
  `ip/hotspot/host` и `show/ip/hotspot` приводятся к массиву (массив / объект по MAC /
  невалидный JSON), поэтому устройства показываются даже при нестандартном ответе;
- подсказка в пустой вкладке показывает все три сырых ответа RCI (hotspot, host, arp) —
  диагностика причины прямо в браузере.

## 1.0.0 — 2026-10-27

Первый публичный выпуск после аудита исходной сборки.

Безопасность:
- вход в панель по паролю (задаётся при первом открытии), сессии в cookie `HttpOnly`, `SameSite=Strict`;
- убран `Access-Control-Allow-Origin: *`; POST-запросы принимаются только с заголовком `X-Requested-With`;
- проверка `Host` против DNS rebinding;
- панель слушает только адрес домашней сети (br0);
- поля настроек проверяются по белому списку; расписание `update_cron` — строго 5 полей cron (раньше через него выполнялась любая команда от root);
- подписка и XKeen скачиваются с проверкой TLS-сертификата (убран `curl -k`), `file://` в ссылке подписки запрещён;
- имена серверов из подписки экранируются в панели (раньше подписка могла выполнить скрипт);
- ссылка подписки не пишется в журнал целиком.

Установка:
- веб-панель работает на lighttpd (в BusyBox из Entware нет httpd — раньше панель не запускалась на чистом роутере);
- XKeen ставится штатной автоустановкой `xkeen -i auto` (раньше установщик по SSH зависал на скрытых вопросах);
- флешка: автонастройка запускается сразу после установки Entware и повторяется при следующих загрузках, если не удалась; архивы для aarch64, mipsel и mips;
- общий сценарий `xkeen-happ-setup` для SSH и флешки, повторный запуск безопасен;
- политика XKeen не перезаписывает уже назначенную домашней сети политику; DNS-over-TLS/HTTPS не меняется, если уже настроен; ключи `--no-dns`, `--no-policy`;
- `xkeen-happ-uninstall` для удаления.

Подписки:
- модель роутера и версия прошивки в заголовках `x-device-model` / `x-ver-os` берутся из роутера;
- замер пинга всех серверов параллельно; поддержка IPv6-адресов;
- битая vmess-ссылка пропускается, а не ломает разбор всей подписки;
- режим «всё, кроме РФ» использует `domain:ru|su|xn--p1ai`.

Панель:
- статус Xray и модель роутера показываются реальные (раньше были зашиты «Подключено» и «Netcraze Ultra»);
- убраны демонстрационные цифры трафика и даты;
- вёрстка для телефона.
