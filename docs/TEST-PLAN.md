# План проверки на роутере

Перед тестом: зайдите в веб-интерфейс роутера и сохраните резервную копию конфигурации («Управление» → «Общие настройки» → «Конфигурация» → скачать startup-config). Отключить XKeen и вернуть всё можно командой `xkeen-happ-uninstall --all` и загрузкой этой копии.

## Тест А. По SSH (Entware уже стоит) — 10 минут

1. `cd /opt/tmp && sh install-xkeen-sub.sh --sub "ССЫЛКА"` (или `curl -fsSL … | sh -s -- --sub "ССЫЛКА"`).
2. Ждём «Готово». Если ошибка — прислать последние 30 строк вывода.
3. `xkeen-happ-doctor` — прислать вывод целиком.
4. Открыть `http://192.168.1.1:8099` с телефона: задать пароль, увидеть список серверов, нажать «Диагностика».
5. С телефона в Wi-Fi открыть 2ip.ru — должен быть IP VPN-сервера; открыть ya.ru и youtube.com.
6. Переключить режим «Весь трафик через VPN» → «Сохранить» → 2ip.ru снова. Вернуть «Только заблокированные».
7. `killall xray`, подождать до 5 минут: `pidof xray` должен снова показать процесс (сторож).
8. Перезагрузить роутер: через 2–3 минуты панель открывается, VPN работает.

## Тест Б. Флешка (чистый роутер или чистая флешка) — 20 минут

1. Флешка EXT4, папка `install`. Сначала **универсальный вариант**: положить все три файла из `usb/all/install/`.
2. «Управление» → «OPKG» → выбрать флешку → «Сохранить». Смотреть «Системный журнал» (фильтр `installer`).
3. Если прошивка ругается на файл чужой архитектуры — оставить один файл из `usb/<процессор>/install/` и повторить. Записать, как повела себя прошивка.
4. Через 10 минут: `http://192.168.1.1:8099`, задать пароль, вставить подписку.
5. Если панель не открылась — по SSH (порт 222, root/keenetic): `cat /opt/var/log/xkeen-happ-bootstrap.log` и `xkeen-happ-doctor`.

## Что прислать

- вывод `xkeen-happ-doctor`;
- при ошибке — `/opt/var/log/xkeen-happ-bootstrap.log` или вывод установщика;
- модель роутера и версию KeeneticOS;
- результат пункта 3 теста Б (берёт ли прошивка свой файл из нескольких).
